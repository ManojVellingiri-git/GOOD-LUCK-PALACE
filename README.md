# Good Luck Palace (Est. 1983)

A luxury heritage departmental store web application for Good Luck Palace, Coimbatore.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ManojVellingiri-git/GOOD-LUCK-PALACE)

## Features
- **Cinematic Editorial Homepage**: Smooth entrance animations, dynamic ticker marquee, and asymmetric department grids.
- **Dedicated Multi-Category Shop Catalogue**: Full product catalogue at `/shop` with category filters, Quick-View modal, and Wishlist toggling.
- **Product Experience**: In-depth detail views, WhatsApp order integration, and real-time basket updates.
- **FastAPI Backend**: Products API, orders management, and admin dashboard.

1. **Build Command**: `npm install && npm run build`
2. **Publish Directory**: `dist`
3. **Rewrite Rule**: `/*` -> `/index.html`
